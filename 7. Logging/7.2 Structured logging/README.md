# Структурное логирование в Go с библиотекой Zap

Этот проект демонстрирует возможности библиотеки `zap` для структурированного логирования в Go.

## Структура проекта

Каждая тема вынесена в отдельную папку с собственным `main.go` для удобства демонстрации:

- `basic_examples/` - базовые примеры использования zap
- `logger_types/` - различные типы логгеров (development/production)
- `logging_levels/` - работа с уровнями логирования
- `structured_fields/` - логирование с дополнительными полями
- `custom_config/` - пользовательская конфигурация и направления вывода

## Установка

```bash
go mod init structured-logging-examples
go get go.uber.org/zap
```

## Запуск примеров

Каждый пример запускается отдельно:

```bash
# Базовые примеры
cd basic_examples && go run .

# Типы логгеров
cd logger_types && go run .

# Уровни логирования
cd logging_levels && go run .

# Структурированные поля
cd structured_fields && go run .

# Пользовательская конфигурация
cd sampling && go run .
```

## Основные возможности

### Базовое логирование
- `logger.Info()` - информационное логирование
- `logger.Error()` - логирование ошибок
- `logger.Warn()` - предупреждения
- `logger.Debug()` - отладочное логирование

### Уровни логирования
- `zap.DebugLevel` - отладка
- `zap.InfoLevel` - информация
- `zap.WarnLevel` - предупреждения
- `zap.ErrorLevel` - ошибки
- `zap.FatalLevel` - критические ошибки

### Типы логгеров
```go
// Для разработки
logger, _ := zap.NewDevelopment()

// Для продакшена
logger, _ := zap.NewProduction()
```

### Структурированные поля
```go
logger.Info("Сообщение",
    zap.String("user_id", "12345"),
    zap.Int("attempt", 3),
    zap.Bool("success", true),
)
```

### Направления вывода
- Консоль (`stdout`, `stderr`)
- Файлы
- Множественные направления
- JSON формат

## Отличия от стандартного логирования
- ❌ Стандартный `log`: только текстовый вывод
- ✅ Zap: JSON структура для анализа
- ❌ Стандартный `log`: нет уровней
- ✅ Zap: Debug, Info, Warn, Error, Fatal
- ❌ Стандартный `log`: ограниченная настройка
- ✅ Zap: множественные направления вывода
