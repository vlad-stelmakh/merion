# Стандартное логирование в Go

Этот проект демонстрирует возможности встроенного пакета `log` в Go.

## Структура проекта

Каждая тема вынесена в отдельную папку с собственным `main.go` для удобства демонстрации:

- `basic_examples/` - базовые примеры использования log пакета
- `custom_loggers/` - создание пользовательских логгеров  
- `output_destinations/` - вывод логов в разные места назначения
- `formatting/` - различные способы форматирования сообщений
- `flags_and_prefix/` - работа с флагами и префиксами

## Запуск примеров

Каждый пример запускается отдельно:

```bash
# Базовые примеры
cd basic_examples && go run .

# Пользовательские логгеры
cd custom_loggers && go run .

# Места назначения логов
cd output_destinations && go run .

# Форматирование
cd formatting && go run .

# Флаги и префиксы
cd flags_and_prefix && go run .
```

## Основные возможности

### Базовое логирование
- `log.Println()` - простое логирование
- `log.Printf()` - логирование с форматированием
- `log.Fatal()` - критические ошибки (завершает программу)
- `log.Panic()` - паника (вызывает panic)

### Флаги логирования
- `log.Ldate` - дата
- `log.Ltime` - время
- `log.Lmicroseconds` - микросекунды
- `log.Llongfile` - полный путь к файлу
- `log.Lshortfile` - короткое имя файла
- `log.LUTC` - UTC время
- `log.LstdFlags` - стандартные флаги (дата + время)

### Пользовательские логгеры
```go
logger := log.New(os.Stdout, "[PREFIX] ", log.LstdFlags)
```

### Места назначения
- Стандартный вывод (`os.Stdout`)
- Поток ошибок (`os.Stderr`)
- Файлы
- Буферы памяти
- Множественные места назначения
