# Команды для демонстрации параллельных тестов

## Основные команды

```bash
# 1. Основной запуск с подробным выводом
go test -v

# 2. Обнаружение race condition
go test -race

# 3. Бенчмарки с параллельностью
go test -bench=. -benchtime=3s

# 4. Ограничение параллельности
go test -v -parallel 2

# 5. Краткий режим (без подробностей)
go test

# 6. Запуск конкретного теста
go test -run TestParallel_Calculator -v

# 7. Только бенчмарки
go test -bench=BenchmarkSlowCalculation_Parallel

# 8. Комбинированный запуск
go test -v -race -bench=.
```

## Ожидаемые результаты

### 1. Разница во времени
- Последовательно: ~400ms
- Параллельно: ~0.07ms (родительский тест)

### 2. Race detector
- Обнаружит DATA RACE в UnsafeIncrement
- Покажет точные строки кода с проблемой

### 3. Benchmark
- Обычный: ~100ms/op
- Параллельный: ~9ms/op (в 11 раз быстрее)

### 4. Параллельность
- PAUSE/CONT показывает управление горутинами
- -parallel 2 ограничивает до 2 одновременных тестов
