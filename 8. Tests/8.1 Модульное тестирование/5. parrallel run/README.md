# Параллельное выполнение тестов

Этот пример демонстрирует как использовать параллельное выполнение тестов в Go для ускорения тестирования.

## Основные концепции

### 1. Последовательное выполнение (по умолчанию)
```go
func TestSequential_Calculator(t *testing.T) {
    // Тесты выполняются один за другим
}
```

### 2. Параллельное выполнение
```go
func TestParallel_Calculator(t *testing.T) {
    t.Run("тест", func(t *testing.T) {
        t.Parallel() // включает параллельное выполнение
        // тест код
    })
}
```

## Файлы в проекте

- `calculator.go` - функции с искусственными задержками для демонстрации
- `parallel_tests_test.go` - тесты демонстрирующие различные аспекты параллельности

## Команды для запуска

```bash
# Обычный запуск тестов
go test -v

# Запуск с ограничением параллельности
go test -v -parallel 2

# Бенчмарки (показывает ~11x улучшение производительности)
go test -bench=. -benchtime=3s
```

## Результаты демонстрации

### Время выполнения
- **Последовательные тесты**: ~404ms
- **Параллельные тесты**: ~77µs (родительский тест)

### Бенчмарки 
- **Обычный**: ~100ms на операцию
- **Параллельный**: ~9ms на операцию (**~11x быстрее!**)

## Что демонстрируется

1. **Разница во времени выполнения** между последовательными и параллельными тестами
2. **Правильное использование замыканий** в параллельных тестах (`tt := tt`)
3. **Параллельные бенчмарки** с `RunParallel`
4. **Управление параллельностью** с флагом `-parallel`

## Важные замечания

- Используйте `t.Parallel()` только для независимых тестов
- Будьте осторожны с общими ресурсами (файлы, глобальные переменные)
- Помните про замыкания в циклах (`tt := tt`)
- Контролируйте количество параллельных тестов с `-parallel N`
- Для демонстрации race condition см. папку "6. race condition"
