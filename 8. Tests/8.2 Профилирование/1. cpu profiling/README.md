# CPU Profiling

Пример CPU профилирования с вычислительно-интенсивными операциями.

## Запуск

```bash
go run main.go
```

Программа создаст файл `cpu.prof` с данными профилирования.

## Анализ в консоли

```bash
# Интерактивный режим
go tool pprof cpu.prof

# Основные команды в pprof:
# top     - топ функций по использованию CPU
# top10   - топ 10 функций
# list <функция> - исходный код функции с аннотациями
# web     - граф вызовов (требует graphviz)
# png     - сохранить граф как PNG
# exit    - выход
```

### Примеры команд:
```
(pprof) top
(pprof) top -cum
(pprof) list main.calculatePrimes
(pprof) web
```

## Анализ в браузере

```bash
# Веб-интерфейс на localhost:8080
go tool pprof -http=:8080 cpu.prof
```

### Возможности веб-интерфейса:
- **Graph** - граф вызовов функций
- **Flame Graph** - flame график для анализа стека
- **Top** - таблица топ функций
- **Source** - аннотированный исходный код

## Что показывает профиль

1. **calculatePrimes** - поиск простых чисел (алгоритмическая сложность)
2. **performMatrixOperations** - умножение матриц (циклы)
3. **simulateStringOperations** - неэффективная работа со строками

## Ключевые метрики

- **flat** - время, проведенное в самой функции
- **cum** - совокупное время (включая вызываемые функции)
- **%** - процент от общего времени
