# gRPC Калькулятор - Клиент

Простой клиент для gRPC сервера калькулятора, который демонстрирует базовые операции с gRPC.

## Возможности

- Подключение к gRPC серверу
- Выполнение математических операций (сложение, вычитание, умножение, деление)
- Обработка ошибок (деление на ноль, неизвестные операции)
- Демонстрационные примеры
- Интерактивный режим работы

## Структура проекта

```
client/
├── calculator/
│   └── calculator.proto     # Proto файл с описанием сервиса
├── generated/
│   ├── calculator.pb.go     # Сгенерированные структуры
│   └── calculator_grpc.pb.go # Сгенерированный gRPC код
├── go.mod                   # Go модуль
├── main.go                  # Основной файл клиента
└── README.md               # Этот файл
```

## Запуск

### Предварительные требования

1. Убедитесь, что gRPC сервер запущен (из папки ../server)
2. Установлены необходимые зависимости Go

### Установка зависимостей

```bash
cd client
go mod tidy
```

### Запуск клиента

```bash
go run main.go
```

## Использование

Клиент работает в двух режимах:

### 1. Демонстрационный режим

При запуске клиент автоматически выполнит несколько примеров операций:
- Сложение: 10.5 + 5.3
- Вычитание: 20.0 - 8.5
- Умножение: 4.0 * 7.0
- Деление: 15.0 / 3.0
- Деление на ноль (демонстрация ошибки)
- Неизвестная операция (демонстрация ошибки)

### 2. Интерактивный режим

После демонстрации клиент переходит в интерактивный режим, где вы можете вводить свои операции.

Формат ввода: `число операция число`

Доступные операции:
- `add` - сложение
- `subtract` - вычитание
- `multiply` - умножение
- `divide` - деление

Примеры:
```
> 10.5 add 5.3
Результат: 15.80

> 20 subtract 8
Результат: 12.00

> 4 multiply 7
Результат: 28.00

> 15 divide 3
Результат: 5.00
```

Для выхода введите `exit`.

## Примеры ошибок

```
> 10 divide 0
Ошибка: Division by zero

> 5 power 2
Ошибка: Unknown operation
```

## Технические детали

- Клиент подключается к серверу на `localhost:50051`
- Используется небезопасное соединение (insecure) для простоты
- Таймаут операций: 1 секунда
- Поддерживает числа с плавающей точкой (float64)
