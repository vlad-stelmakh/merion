# Timecoder (Telegram-бот)

Бот для YouTube-таймкодов голов. Сейчас принимает картинку результата матча и 2 ссылки на видео таймов.

## Быстрый старт

```bash
cd timecoder
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
# впиши BOT_TOKEN=...
python bot.py
```

## Как пользоваться

1. `/new`
2. Пришли **картинку** с результатом из группы турнира  
   (лучше с **подписью** — список голов текстом)
3. Пришли **2 ссылки** на YouTube (1-й и 2-й тайм) одним сообщением

Ответ — текст с таймкодами для комментария YouTube.

## Логика таймкодов

- Таймы по **25 минут** (`HALF_MINUTES=25`)
- Отступ **−10 сек** (`YT_OFFSET_SECONDS=10`)
- Голы `≤ 25'` → 1-е видео
- Голы `> 25'` (например `41'`) → 2-е видео: `(минута − 25) × 60 − 10`

Пример: `41'` → `15:50`

## Переменные окружения

```bash
BOT_TOKEN=
HALF_MINUTES=25
YT_OFFSET_SECONDS=10
```
